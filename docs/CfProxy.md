# Свой домен для CF-прокси

CF-прокси — запасной путь до серверов Telegram через Cloudflare. В приложении уже есть общий список доменов, но им пользуются все сразу: Cloudflare ограничивает число одновременных подключений, и когда общие домены перегружены, они отвечают ошибкой 503, а Telegram подвисает. Свой домен — только ваш.

Нужен любой домен — примерно 150 ₽ в год. Cloudflare бесплатный.

## Как настроить

1. **Добавьте домен в Cloudflare.** Купите его прямо в Cloudflare или добавьте уже имеющийся и смените у регистратора NS-серверы на те, что покажет Cloudflare ([инструкция Cloudflare](https://developers.cloudflare.com/dns/zone-setups/full-setup/setup/)).
2. **SSL/TLS → Overview** — выберите режим **Flexible**.
3. **DNS → Records → + Add Record** — добавьте шесть записей типа `A`. Облачко **Proxied** (оранжевое) должно быть включено — так записи создаются по умолчанию:

| Name | IPv4 |
|---|---|
| `kws1` | `149.154.175.50` |
| `kws2` | `149.154.167.51` |
| `kws3` | `149.154.175.100` |
| `kws4` | `149.154.167.91` |
| `kws5` | `149.154.171.5` |
| `kws203` | `91.105.192.100` |

   В приложении записи можно скопировать одной кнопкой: «О программе» → «Справка» → «Свой домен CF-прокси» → «Скопировать DNS-записи».

4. В приложении: **Настройки → Cloudflare → Свои домены CF-прокси** — впишите домен без `kws` и без `https://`, например `example.ru`, и нажмите **Сохранить**. Несколько доменов — через запятую.

**Проверить:** кнопка **Проверить домен** прямо под полем покажет по каждому датацентру, отвечает ли запись, — если какой-то не хватает, будет видно, какой.

> Если после настройки на аккаунте без Premium не грузятся фото и видео, оставьте в «Настройки → Датацентры» только строку `4:149.154.167.220`.
